# SOP-01 素材解析

> **目标**：在动笔前 100% 掌握原料，建立"原文 ↔ 论文"的可追溯映射，把原文自身的问题（截断、缺失、错位）提前暴露并让客户拍板。
> **耗时参考**：0.5 天 | **产出**：映射表 + 原文问题登记表 + 卡点确认清单

## 1. 原料清单（开工前向客户索齐）

| 原料 | 本项目对应 | 用途 |
|---|---|---|
| ① 内容唯一源 | `原始论文摘取.md`（约 2000 行，`#`/`##`/`###` 三级标题分章）（如果没有需要找到相应原始资料或询问用户，并可支持其他格式文件形式） | 论文全部内容的唯一出处 |
| ② 参考文献表 | `参考文献.md`（100 条 GB/T 7714）（如果没有需要找到相应原始资料或询问用户） | `[N] → \cite{refN}` 映射 |
| ③ 图片库 | `image.png`、`image-1.png` ~ `image-30.png`（如果没有需要找到相应原始资料或询问用户） | 与原文图号一一对应 |
| ④ 借鉴论文 1、2、3（数据集章风格） | （如果没有需要找到相应原始资料或询问用户） | 只学陈述方式，不引内容 |
| ⑤ 借鉴论文 1、2、3等等（整体风格） | （如果没有需要找到相应原始资料或询问用户） | 只学句式/结构/排版 |
| ⑥ 对齐点备忘 | `写论文需要对齐的点.md` | 记录数据矛盾（如类别数 22 vs 24） |
| ⑦ 客户口语补充 | 会话中的描述（如方法总体构成） | 需学术化整合进论文 |

## 2. 解析动作（按序执行）

### 2.1 通读内容源
- 用标题层级定位各章行号范围，产出"章节地图"：

```
# 摘要               1-32
# 引言和相关工作      33-381   （要拆成两节写）
# 2 数据集           383-820   （章末有作者自批注"内容太多要取舍"）
# 3 方法             822-1335  （缺总体方法名与框架图，需新写）
# 4 实验             1337-1954 （两套实验设置不同，要分开写）
# 5 总结与展望        1956-2003 （第4点总体总结是占位注释，需新写）
```

- **特别留意原文中的括号批注**——那是作者（客户）留下的写作指令，如"可以起个方法名""这一章内容量太多要主从分明取舍""看要不要把A描述换成B"，全部摘出形成任务清单。

### 2.2 建立图片映射表
（如果没有需要找到相应原始资料或询问用户）
```
原文图号 → 文件名 → 论文新图号（写作时确定）
图 2-1 → image-1.png → 图 2
图 3-1 → image-15.png → 图 11 ...
```
用 `file figures/*.png` 获取每张图分辨率，**标记长宽比异常的竖长图**（如 182×345），这类图排版时必须按 height 约束（见 SOP-06 陷阱 5）。

### 2.3 建立引用映射并抽查作者
- `[N] → \cite{refN}` 一一对应写入 refs.bib（100 条全量转入，写作时按需引用）。
- **抽查方法**：随机抽 5~10 条，核对"引用处的语境 ↔ 文献 title/author"是否对口。本项目实测发现 4 组错位：
  - 低光逆ISP 错引盲去卷积论文（应为 Unprocessing）
  - PSNR/SSIM 处错引（应为 SSIM 原始论文）
  - mAP 处错引（应为 COCO）
  - t-SNE 处引了 GAN 应用论文（参考文献表中无 t-SNE 原文 → 换条目内容，保持总数）
- 引用修正原则：**先按原文引用写作 + 汇总错位清单让客户拍板 → 客户确认后统一修正**，不要静默改动。

### 2.4 原文问题登记表（边读边记）

| 类型 | 本项目实例 | 处置 |
|---|---|---|
| 内容截断 | "二值硬切分结果数值缺失"段 | 请客户恢复原文后再写入对应章节 |
| 数据缺失 | 表 4-3 末行精确率空缺 | 从正文取值补入 + 表注标"待复核" |
| 图号混乱 | 3.3 节用"图 4-x"、表 3-x | 写作时统一重排为全文连续编号 |
| 引用错位 | 上述 4 组 | 卡点报客户确认后修正 |
| 章节占位 | 第5章第(4)点总体总结未写 | 标记"需新写"，锚定相关章节内容撰写 |
| 重复矛盾 | 消融设置"CSRC 关闭"与数值矛盾 | 行文绕开矛盾表述，按数值口径写 |
| 数据版本矛盾 | 数据集 22 类 vs 24 类 | **必须客户拍板**（本项目定为按原文 24 类） |

### 2.5 识别"需新写"的部分
原文是学位论文体，转期刊体通常缺：
- **方法总体统称与总体框架**（方法名 + 二阶段/多模块关系的形式化定义 + 框架图）
- **总体方法的总结段**（结束语中）
- **期刊式摘要**（融入总体方法名与关键数字）
这些需从客户口语补充 + 原文各章内容学术化整合，**先列写作方案给客户确认再动笔**。
