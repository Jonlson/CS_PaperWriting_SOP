# SOP-05 校验体系

> **目标**：定稿前证明"论文数据 ↔ 原文数据"逐值一致。全部命令在本项目实测通过。
> **时机**：全文写完后一次性执行（每章编译验证不等于数据校验）。

## 1. 表格数字逐值比对（核心方法）

**原理**：所有指标都是含小数点的数（`X.XX/X.XXX` 或百分比），提取"纯小数序列"对比，可天然排除年份、引用编号等干扰。

```bash
# 提取函数：只取含小数点的数字并串成一行
norm() { grep -oE '[0-9]+\.[0-9]+' | tr -d '\n'; }

# 单表比对（原文行号区域 vs 论文 tex 行号区域）
diff <(sed -n '1378,1393p' 原始论文摘取.md | norm) \
     <(sed -n '56,74p' paper/sections/experiments.tex | norm)
# 无输出 = 一致
```

**本项目实测结果**：8 张表全部一致。

**注意事项**：
- 论文表格若做左右并排（如 24 类别 `lcc|lcc`），数字顺序与原文逐行序不同 → diff 报差异属**假阳性**，需按"左列=原文前半、右列=原文后半"的交错关系逐值核对（写循环脚本或人工核）。
- 预期内差异要在报告里说明（如原文表格缺值、按正文补入）。

## 2. 关键标量出现次数对照

```bash
for n in 24 5229 68732 4183 20915 1046 5230 27.82 27.94 23.14 93.3 91.4 27.6; do
  o=$(grep -c "$n" 原始论文摘取.md)
  p=$(grep -rc "$n" paper/sections/*.tex | awk -F: '{s+=$2}END{print s}')
  echo "$n: 原文${o}处 论文${p}处"
done
```
**判读**：次数不同不一定是错误——正文精简会减少重复提及、结束语/摘要会新增提及。关键是**数值本身两边都存在且语境正确**；对次数骤减的值抽查其表格内是否存在。

## 3. 公式符号级抽查

从转换后的公式中抽 3~5 条最复杂的（嵌套最深、下标最多），与原文乱码公式逐符号比对：
```bash
sed -n '663,664p' 原始论文摘取.md                    # 原文公式行
grep -A2 "tilde{I} = .mathcal{F}" sections/dataset.tex  # 论文对应公式
```
核对：结构（括号嵌套）、运算符（⊙ * ⋅）、上下标、符号方向（CCM^{-1}）。

## 4. 引用覆盖校验

```bash
# 被引编号集合与总数
grep -ohE 'ref[0-9]+' paper/sections/*.tex | sort -u
grep -ohE 'ref[0-9]+' paper/sections/*.tex | sort -u | wc -l   # 应 = main.bbl 的 bibitem 数
# 未引用条目
for i in $(seq 1 100); do
  grep -ohE 'ref[0-9]+' paper/sections/*.tex | sort -u | grep -q "ref$i$" || printf "$i "
done
```
**未引条目处置**：逐条核对原文是否引用——若原文自身未引（学位论文他章用）则忽略；若是因引用修正而弃用（如错引修正）则记录说明。bibtex 只输出被引条目，顺序编码自动重排。

## 5. 编号与交叉引用连续性

```bash
grep -oE 'newlabel\{fig:[a-z-]+\}\{\{[0-9]+\}' main.aux   # 图号应 1..N 连续
grep -oE 'newlabel\{tab:[a-z-]+\}\{\{[0-9]+\}' main.aux   # 表号应 1..M 连续
grep -ci 'undefined' main.log                              # 交叉引用必须 0
```

给客户的统计表（从 aux 提取）：

| 章节 | 页码 | 页数 | 图 | 表 | 公式 |
|---|---|---|---|---|---|
| （各章 + 子章节） | `numberline` 提取 | 首末页差 | 源文件 `grep -c 'begin{figure*}'` | 同理 table* | 同理 equation |

注意：aux 的 numberline 提取时，标题含 LaTeX 宏（`\dataset{}` 等）会破坏简单正则，用宽松模式或直接 grep 原始行。
