# 论文优化写作与排版 SOP（标准作业流程）

> **适用场景**：客户提供"杂糅的完整内容"（学位论文/项目报告/口语化笔记等原始材料），需要产出一篇**内容准确、排版规范、学术风格、科学逻辑完整**的期刊论文（先中文版）。
>
> 本 SOP 由 ESDS/ETD-Net 论文项目（2026-10，电力仓库图像增强+目标检测，7 章节全部完成并通过逐值校验）实战沉淀而成，所有参数与命令均经过实际验证。

---


## 三、角色与纪律

- **AI 执行者**：内容**必须**源于客户提供的原文材料，只做提取、压缩、LaTeX 规范化，不自由发挥、不引入外部事实；遇到矛盾/缺失/取舍，**列卡点让客户拍板**，不自作主张。
- **客户**：提供内容源、参考文献表、图片；对卡点做决策；视觉验收 PDF（AI 只能文本验证，无法目视渲染效果，**渲染质量必须请人翻看 PDF**）。
- **验证纪律**：PDF 状态一律用 `main.aux`/`main.log` 文本方式核验（章节页码、图表标签、错误计数），不能用视觉方式读 PDF。

## 四、本项目沉淀的关键数据（供校对参考）

- 产出一篇 35 页双栏论文：26 图、8 表、63 式、93 条被引文献
- 全流程周期：素材解析 0.5 天 → 模板 0.5 天 → 逐章（每章 1 轮确认+1 轮写作）→ 排版治理 2 轮 → 校验 1 轮
- 校验结果：8 张表逐值一致、公式符号级抽查一致、引用 0 未定义
