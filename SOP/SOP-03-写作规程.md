# SOP-03 写作规程

> **目标**：把原文内容按期刊学术规范逐章转化，全程可追溯、卡点必上报、每章必验证。
> **核心纪律**：内容源于原文，AI 只做"提取 + 压缩 + LaTeX 规范化"，不做自由创作。

## 1. 写作铁律（不可违反）

1. **内容唯一来源**：正文内容必须能在原文材料中找到出处（客户口语补充需学术化后经确认）。禁止凭空引入外部事实、数据、文献。
2. **尽量不改原文表述**：优先复用原句，只做：删冗余、并重复、规范术语、学术化口语。
3. **详略取舍三原则**：
   - 自身设计/实验**放大**（导师要求"自身设计占图 50% 以上"）
   - 公共基线/通用背景**一句话带过**（有对比表时正文不再罗列数据）
   - 学位论文体例删：章小结、"本章/前几章"措辞、组织结构段
4. **原文矛盾不静默处理**：按数值口径行文并登记，或上报卡点。
5. **序号/编号一切重新排**：图表公式全文连续编号，正文引用一律 `\ref`/`\cite`，不硬编码。

## 2. 各章写作范式（五段式期刊结构）

| 章 | 结构范式 | 关键要求 |
|---|---|---|
| 0 引言 | 任务定义+政策产业背景(看具体信息，有些不需要) → 复杂场景挑战 → 现有四类瓶颈（其一~其四） → 方法概述（含总体方法名）→ 贡献点 1)~4) | 贡献点=数据集/总体框架/各模块创新，"动词开头+关键数字+价值"，每条 2~3 行 |
| 1 相关工作 | 三小节组合：相同任务不同方法 / 相同方法不同任务 / 类似任务类似方法 | 保留里程碑+近两年方法，早期一句带过；每小节末归纳不足衔接本文 |
| 2 数据集 | 调研与动机（一句话/数据集+对比表）→ 采集与预处理（设备/统计/命名/标注质量保障）→ 降质生成方法 → 子集与评价指标 | 标注机制显式化（多人交叉验证）；评价指标公式可文字化（客户确认后） |（如果没有需要找到相应原始资料或询问用户，不是所有论文都有自制数据集）
| 3 方法 | 总体框架（新写：动机+框架图+形式化定义+两模块协作）→ 模块一 → 模块二 | 总体框架图缺失时先画 TikZ 占位并声明可替换；每模块=动机(压缩)+机制+公式 |
| 4 实验 | 实验设置（不同任务的设置分开写）→ 对比 → 消融 → 可视化 | 所有实验保留（覆盖要求），分析文字精简约 40%，结论句式化"X 取得 Y，对应 Z 设计" |
| 5 结束语 | 1)~4) 总结（每点百字：做了什么+关键数字+价值）+ 展望一段 | 总体方法总结若原文缺失需新写，锚定方法章与实验章结论 |
| 摘要 | 背景 → 总体方法名 → 分项工作+关键数字 → 价值 | 中英双语；指标数值必须与正文一致 |
（如果没有需要找到相应原始资料或询问用户对应章节设置）
**三级序号体系**：`\subsection` 二级；段内用 `\textbf{1)XXX。}` 黑体段头（不用 enumerate、不用（1））。

## 3. 逐章写作循环（每章必走）

```
① 提取：按章节地图读该章原文全文（含作者批注）
② 方案：列"结构映射 + 详略取舍 + 待拍板卡点"表格报客户
③ 拍板：客户确认方案与卡点（默认做法 vs 备选）
④ 写作：生成 sections/xx.tex（头部写映射注释）
⑤ 编译：全链编译，0 错误 0 未定义引用 0 Overfull 才算过
⑥ 汇报：章结构表 + 取舍记录 + 新发现的原文问题 + 下章预告
```

## 4. 卡点上报格式（每章方案必附）

| # | 卡点（含原文位置） | 默认做法 | 备选 |
|---|---|---|---|
| 1 | xxx | xxx | xxxx（需全文同步改） |

常见卡点类型：贡献点条数、删/留某段、具体指标数字留否、引用错位修正、概念口径（如"总体方法 vs 子模块"谁作主语）、图表去留。

## 5. 概念口径管理（多模块方法论文必备）

**案例**：xxx = xxx(增强) + xxxxx(检测) 级联总体；xxx 只是xxx。
- 实验章总括句、可视化结论 → 用**总体方法名**
- 检测器列表、表格"检测器"列、模块消融归因 → 用**模块名**（此时增强先验相同，差异来自模块）
- 方法章各节首句显式声明身份（"作为 xxxxx 的检测阶段，……"）
- 全文写完后**专项通查一遍**口径混用。

## 6. 修订循环（客户反馈处理）

收到反馈后按类处理，每轮结束重编译+汇报：

| 反馈类型 | 动作 | 本项目实例 |
|---|---|---|
| 排版参数类 | 改 main.tex 版式区，一处生效 | 页边距/栏距/页眉页脚 |
| 结构类 | 重排该章结构（合并/删除/新增） | 调研段压一句话、删章小结 |
| 内容凝练类 | 按要点重写（保数字删解释） | 贡献点减半、实验分析 -40% |
| 视觉问题类 | 先定位根因（log/图分辨率）再改 | 图题截断、图超页、浮动体延迟 |
| 格式规范类 | 全文批量统一 | 序号 1)、公式引导句冒号 |

**视觉问题必须先查根因再动手**：如"题注被截断"真因是图超页高把题注推出页底 + `\centerline` 不换行，双修复才能除根。
